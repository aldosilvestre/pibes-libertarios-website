Fotos públicas desde GitHub

  1. En el repositorio, abrí assets/members/ y usá Add file → Upload files para subir las fotos.
  2. Editá members.js y completá el campo photo de cada persona, por ejemplo assets/members/member-01.jpg.
  3. Guardá los cambios en GitHub. Cuando Pages termine de publicar, las fotos serán visibles para todos.

Si reemplazás una foto conservando su nombre y carpeta, no necesitás volver a editar members.js.
