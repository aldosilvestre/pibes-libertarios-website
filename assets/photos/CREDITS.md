# Photograph credits

These are photographs or digitized real materials, not drawings, vector art, 3D renders or AI-generated substitutes. Licenses and sources were checked through Wikimedia Commons API `prop=imageinfo&iiprop=url|extmetadata|mime|size` with `iiurlwidth=1800`. Raw API responses for the selected sources are preserved in `commons-metadata.json`. Downloads used the returned thumbnail paths on `upload.wikimedia.org` with a descriptive User-Agent.
